# cv

This repository is just my CV using the project [RenderCV](https://github.com/rendercv/rendercv)

# Requerimients

- For use with VisualStudio code we recomend using the extensions defined in the extensions.json
- Install Python 3.12+
- Install Pip
    - Windows: py -m ensurepip --upgrade
    - Linux: python -m ensurepip --upgrade
    - Mac: python -m ensurepip --upgrade
- Install RenderVC
    - pip install "rendercv[full]"
